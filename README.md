## О проекте

«КнигоСворот» — некоммерческая веб-платформа, которая позволит жителям города находить книги для обмена, договариваться об обмене с другими пользователями и назначать место личной встречи.

Заказчик проекта — директор городской центральной библиотеки.

## Примечания к переносу

- Рукописные артефакты ПР1 и ПР3 переносятся без изменений по смыслу.
- Документы оформляются в формате Markdown.
- Зачёркнутые и черновые фрагменты не переносятся.


### Присвоенные идентификаторы

Все идентификаторы артефактов сохранены в соответствии с исходными материалами ПР1 и ПР3. Новые идентификаторы при переносе не присваивались.

### Нераспознанные фрагменты

Нераспознанные фрагменты отсутствуют.


### Невыполненные блоки

- Контекстная диаграмма.
- Матрица трассировки.
- Журнал изменений требований.
