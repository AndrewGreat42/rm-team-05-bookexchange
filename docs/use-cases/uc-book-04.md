# UC-BOOK-04. Найти книгу и отправить запрос
## Действующие лица:
*   **Основной:** Участник 1 (инициатор).
*   **Второстепенный:** Участник 2 (автор объявления).
*   **Вспомогательный:** Сервис уведомлений.

## Предусловия:
Участник 1 авторизован, функция поиска доступна.

## Постусловия:
*   **При успехе:** Один запрос сохранен и доступен обеим сторонам; результат отправки уведомления зарегистрирован.
*   **При неуспехе:** Запрос не сохранен; Участнику доступно изменение условий поиска.

## Основной сценарий:
1. Участник вводит название и/или автора книги.
2. Система показывает подходящие доступные объявления.
3. Участник открывает объявление и ознакамливается с ним.
4. Участник отправляет запрос владельцу.
5. Система сохраняет запрос и направляет автору.
6. Участник видит подтверждение создания запроса.

## Альтернативные сценарии:
**1а. Поиск по каталогу**
*   1а.1. Участник выбирает раздел по каталогу.
*   1а.2. Переход к шагу 4 основного сценария.

**2а. Чат недоступен**
*   2а.1. Система сообщает об отсутствии подключения.
*   2а.2. Возврат к шагу 1, чтобы запросить без чата.
