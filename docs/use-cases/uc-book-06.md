# UC-BOOK-06. Оценить участника завершённого обмена

| Поле | Значение |
| --- | --- |
| Основное действующее лицо | Автор оценки с ролью «Участник». |
| Вторичное действующее лицо | Оцениваемый участник. |
| Предусловия | 1. Автор авторизован. <br> 2. Обмен завершён. <br> 3. Автор и получатель оценки являются его сторонами. <br> 4. На начало сценария оценка автора по этому обмену отсутствует. |

## Основной сценарий

1. Участник открывает завершённый обмен и начинает оценивание.
2. Система показывает контрагента и допустимую шкалу от 1 до 5.
3. Участник выбирает значение и отправляет оценку.
4. Система проверяет права, завершение обмена, диапазон и отсутствие ранее сохранённой оценки автора.
5. Система сохраняет оценку и пересчитывает среднее допустимых оценок получателя.
6. Участник видит сохранённую оценку и актуальный рейтинг.

## Альтернативные сценарии

**5a. Первая оценка получателя**

- 5a.1. Ранее полученных оценок нет.
- 5a.2. Рейтинг становится равным новой оценке вместо «Нет оценок».
- 5a.3. Переход к шагу 6.

## Исключительные сценарии

**3a. Отказ от оценивания**

- 3a.1. Участник прекращает ввод без отправки.
- 3a.2. Сценарий заканчивается без оценки; обмен остаётся завершённым.

**4a. Оценка вне шкалы**

- 4a.1. Значение отклоняется.
- 4a.2. Возврат к шагу 3.

**4b. Оценка уже сохранена**

- 4b.1. Система показывает существующую оценку, например при повторной отправке.
- 4b.2. Повторное сохранение и изменение рейтинга не выполняются. Сценарий завершён.

**5b. Ошибка сохранения**

- 5b.1. Система не сообщает об успехе.
- 5b.2. После восстановления связи участник проверяет актуальный результат; если оценки нет, повторяет действие с шага 3.

Сохранение и пересчёт должны давать согласованный результат — предлагаемое правило.

## Постусловия

**При успехе:**

- Одна допустимая оценка сохранена.
- Рейтинг получателя пересчитан.

**При неуспехе:**

- Новая оценка не сохранена.
- Ранее существующие оценки и рейтинг не изменены.
