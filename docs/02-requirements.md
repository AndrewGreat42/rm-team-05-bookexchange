# 2. Требования по Вигерсу

## BR (Бизнес-требования)
*   **BR-1:** Платформа должна обеспечивать бесплатный обмен книгами.
*   **BR-2:** Платформа должна обеспечивать достижение следующих показателей: 2000 активных участников и 500 обменов в месяц за 6 месяцев.
*   **BR-3:** Платформа должна обеспечивать процесс исключения недобросовестных участников.
## UR (Пользовательские требования)
*   **UR-1:** Пользователь должен иметь возможность загружать книгу на платформу с указанием состояния книги.
*   **UR-2:** Пользователь должен иметь возможность совершать поиск необходимой книги.
*   **UR-3:** Пользователь должен иметь возможность создавать запрос на обмен с указанием места и времени встречи.
*   **UR-4:** Пользователь должен иметь возможность оставлять жалобы на других участников.
## FR (Функциональные требования)
*   **FR-1:** Платформа должна обеспечивать добавление книги в каталог по ISBN или вручную.
*   **FR-2:** Платформа должна обеспечивать фильтрацию доступных книг по названию.
*   **FR-3:** Платформа должна обеспечивать обновление рейтинга пользователей после каждого обмена.
*   **FR-4:** Платформа должна позволять согласовывать время и место встречи.
*   **FR-5:** При наличии более 2-х жалоб на пользователя, платформа должна его блокировать.
## NFR (Нефункциональные требования)
*   **NFR-1:** Интерфейс должен быть адаптирован под мобильные устройства.
## CON (Ограничения)
*   **CON-1:** На реализацию проекта должен быть потрачен бюджет не более 800 тыс. руб.
*   **CON-2:** Возможность продажи должна быть исключена.
## EI (Внешние интерфейсы)
*   **EI-1:** Реализация системы оповещений о запросах на обмен (через SMS или e-mail).
*   **EI-2:** Интеграция сервиса с картой города для выбора места встречи.
## Связи (Трассировка)
*   **BR-1** → UR-1 → FR-1, FR-2
*   **BR-1** → UR-2 → FR-4
*   **BR-1** → UR-3 → FR-4
*   **BR-3** → UR-4 → FR-5, FR-3
