# 5. Глоссарий

*   **Участник** — зарегистрированное на платформе физическое лицо. Имеет единый рейтинг и права доступа (как для создания объявления о книге, так и для поиска).
*   **Объявление** — размещенная Участником запись на платформе с информацией о книге. Точка входа для поиска и инициирования обмена.
*   **Запрос на обмен** — действие, инициированное Участником для согласования места и времени встречи по конкретному объявлению.
*   **Обмен** — согласованная сделка по безвозмездной передаче книги. Считается завершенным после физической передачи книги.
*   **Состояние книги** — описание книгой, основанное на её внешнем виде, указываемое Участником при создании объявления для честного информирования (непосредственно влияет на рейтинг).
*   **Рейтинг** — показатель добросовестности Участника. Складывается из количества успешных обменов и количества жалоб. Позволяет реализовать требование заказчика: «понять, кому можно доверять».
